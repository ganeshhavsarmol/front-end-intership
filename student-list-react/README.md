# Student List React Project

## Run

```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite.

## Main files

- `src/App.jsx` - React code and student data
- `src/App.css` - complete styling

## Features

- 1st Year students
- 2nd Year students
- 3rd Year students
- Search by name or roll number
- Filter by year
- Responsive design
