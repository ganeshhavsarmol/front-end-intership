# StudyMate — Student Study Management System

A simple, frontend-only final-year project built with React + Vite.

## Features
- Dashboard
- Subjects with progress
- Notes: add, search and delete
- Tasks: add, complete and delete
- Pomodoro-style study timer
- Student profile saved in localStorage
- Responsive mobile navigation
- No backend/database required

## Run
1. Install Node.js 18+.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:
   npm install
5. Run:
   npm run dev
6. Open the localhost URL shown by Vite.

## Build
npm run build

## Viva explanation
React components build the UI. React Router provides page navigation. React state handles forms, searching and timer behavior. localStorage stores notes, tasks and profile data in the browser. JSON files provide initial demo data.
