SMART STUDENT MANAGEMENT & ID CARD PORTAL
=========================================

Frontend-only Diploma Computer Science final-year project.

Technology: HTML5, CSS3, JavaScript, LocalStorage.

Modules:
1. Login
2. Dashboard
3. Student Profile + Photo
4. Attendance
5. Marks / Results
6. Smart Timetable
7. Assignment Tracker
8. Notices & Notifications
9. Student ID Card Generator
10. Print / Save ID Card as PDF
11. Responsive design

RUN IN VS CODE:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install the Live Server extension.
4. Right-click index.html -> Open with Live Server.
5. Enter any valid email and password.
6. Use the sidebar to open all modules.

SHARE ONLINE:
Upload the extracted project folder to Netlify, Vercel or GitHub Pages to get a public URL.

NOTE: This is a frontend demonstration project. Data is stored in browser LocalStorage. No backend/database is included.
