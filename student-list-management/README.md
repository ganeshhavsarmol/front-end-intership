# Student List Management System

A complete React + Vite student management project for a Diploma CSE project.

## Features

- Dashboard with student statistics
- Add student
- Edit student
- Delete student
- View student profile
- Search students
- Filter by branch and year
- Pagination
- LocalStorage data persistence
- Dark / light mode
- Responsive design for laptop, tablet and mobile
- Demo student data

## Run in VS Code

1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Open Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost URL shown by Vite.

## Build for deployment

```bash
npm run build
```

The production files will be generated in `dist/`.
